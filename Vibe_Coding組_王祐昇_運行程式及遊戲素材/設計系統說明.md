## 🎯 核心設計理念

### **設計原則**
1. **視覺層次優先** - 確保每個層級都有明確的視覺差異
2. **用戶體驗導向** - 遊戲元素保持刺激感，靜態UI注重可讀性
3. **響應式思維** - 從小螢幕開始設計，向上適配
4. **可訪問性考量** - 支援不同用戶需求，設定最小可讀性標準

### **設計目標**
- ✅ 建立清晰的資訊架構
- ✅ 確保每個尺寸都有最佳體驗
- ✅ 使用CSS變數實現一致的縮放
- ✅ 支援高對比度模式

## 📏 字體大小設計系統

### **主要層級 - 基於 1.25 黃金比例**

| 類型 | 變數名稱 | 桌面大小 | 用途 | 修改影響 |
|------|----------|----------|------|----------|
| **Display Title** | `--font-display` | 2.8rem | 遊戲標題 | 影響所有標題大小 |
| **Section Title** | `--font-section` | 1.75rem | 區塊標題 | 影響選擇歌曲/難度標題 |
| **Heading** | `--font-heading` | 1.4rem | 副標題、分數顯示 | 影響遊戲中UI文字 |
| **Body Large** | `--font-body-large` | 1.15rem | 歌曲卡片標題 | 影響卡片內容 |
| **Body** | `--font-body` | 1rem | 按鈕文字 | 影響所有按鈕 |
| **Caption** | `--font-caption` | 0.9rem | 難度描述 | 影響輔助文字 |
| **Mini Text** | `--font-mini` | 0.8rem | 極小畫面輔助用字 | 影響裝飾文字 |

### **遊戲動態元素 - 情境化大小**

| 類型 | 變數名稱 | 桌面大小 | 用途 | 修改注意事項 |
|------|----------|----------|------|--------------|
| **Game Combo** | `--font-game-combo` | 3.5rem | Combo 動畫 | 影響視覺衝擊力 |
| **Game Countdown** | `--font-game-countdown` | 4.5rem | 倒數動畫 | 影響緊迫感 |
| **Game Score** | `--font-game-score` | 1.6rem | 遊戲中分數 | 影響可讀性 |

### **CSS 變數定義**
```css
:root {

  --font-section: 1.75rem;
  --font-heading: 1.4rem;
  --font-body-large: 1.15rem;
  --font-body: 1rem;
  --font-caption: 0.9rem;
  --font-mini: 0.8rem;
  
  /* 遊戲動態元素 */
  --font-game-combo: 3.5rem;
  --font-game-countdown: 4.5rem;
  --font-game-score: 1.6rem;
}
```

### **解鎖條件**

#### **難度解鎖機制**
| 難度等級 | 解鎖條件 | 視覺提示 |
|----------|----------|----------|
| **初學者** | 預設解鎖 | 無鎖定圖示 |
| **休閒玩家** | 完成初學者任一歌曲 | 🔓 解鎖動畫 |
| **困難模式** | 完成休閒玩家任一歌曲 | 🔓 解鎖動畫 |

#### **歌曲解鎖機制**
- **解鎖頻率**：每完成 3 個關卡解鎖一首新歌
- **解鎖順序**：Champion → Bliss → Noise → Canon → HammerMASTER → InspiringDreams → MagicalMoments → MainTheme → inspiringguitar → HappyBirthday

```javascript
showUnlockNotification(type, name) {

        left: 50%;

    document.body.appendChild(notification);
    setTimeout(() => notification.remove(), 2000);
}
```

## 🔧 技術實作指南

### **快速修改指南**

#### **修改字體大小**
1. 找到對應的 CSS 變數
2. 修改 `:root` 中的值
3. 檢查響應式斷點是否需要調整
4. 測試不同裝置的顯示效果

#### **修改顏色**
1. 更新 CSS 變數定義
2. 檢查所有使用該顏色的地方
3. 確保對比度符合可訪問性標準
4. 測試高對比度模式

#### **修改間距**
1. 更新間距變數
2. 檢查佈局是否受影響
3. 測試響應式佈局
4. 確認視覺層次清晰

### **常見問題解決**

#### **問題1：字體大小不一致**
```css
/* 解決方案：使用 CSS 變數 */
.text-display { font-size: var(--font-display); }
.text-section { font-size: var(--font-section); }
.text-heading { font-size: var(--font-heading); }
```

#### **問題2：響應式佈局破損**
```css
/* 解決方案：使用相對單位 */
.container {
    width: min(1200px, 90vw);
    margin: 0 auto;
}
```

#### **問題3：動畫效能問題**
```css
/* 解決方案：使用 transform 而非改變尺寸 */
.animation {
    transform: scale(1.1);
    will-change: transform;
}
```

```javascript
// 處理中文路徑編碼問題
```

### **進度系統初始化**

```javascript
// 確保預設進度存在
ensureDefaultProgress() {
    if (!localStorage.getItem(this.storageKeys.unlockedDifficulties)) {
        localStorage.setItem(this.storageKeys.unlockedDifficulties, JSON.stringify(['beginner']));
    }
    if (!localStorage.getItem(this.storageKeys.unlockedSongs)) {
        localStorage.setItem(this.storageKeys.unlockedSongs, JSON.stringify(['Champion']));
    }
    if (!localStorage.getItem(this.storageKeys.completedLevels)) {
        localStorage.setItem(this.storageKeys.completedLevels, JSON.stringify([]));
    }
}
```

## 🎯 設計原則總結

1. **一致性** - 統一的設計語言和規範
2. **可讀性** - 確保所有文字都清晰易讀
3. **層次性** - 明確的視覺層次結構
4. **響應性** - 適配各種螢幕尺寸
5. **可訪問性** - 支援不同用戶需求
6. **遊戲性** - 保持遊戲的視覺刺激
7. **進度感** - 透過解鎖系統提供成就感
