# Fate Keys 命運節奏 - 設計系統說明

## 🎯 核心設計理念

### 1. **視覺層次優先**
- 確保每個層級都有明確的視覺差異
- 避免相鄰層級過於接近造成混淆
- 建立清晰的資訊架構

### 2. **用戶體驗導向**
- 遊戲元素保持刺激感
- 靜態 UI 注重可讀性和舒適度
- 情境化設計，不同場景使用不同字體大小

### 3. **響應式思維**
- 從小螢幕開始設計，向上適配
- 確保每個尺寸都有最佳體驗
- 使用 CSS 變數實現一致的縮放

### 4. **可訪問性考量**
- 設定最小可讀性標準
- 支援不同用戶需求
- 高對比度模式支援

## 📏 字體大小設計系統

### **主要層級 - 基於 1.25 黃金比例**

| 類型 | 變數名稱 | 桌面大小 | 用途 |
|------|----------|----------|------|
| **Display Title** | `--font-display` | 2.8rem | 遊戲標題（Fate Keys 命運節奏） |
| **Section Title** | `--font-section` | 1.75rem | 區塊標題：選擇歌曲、選擇難度、結算畫面標題等 |
| **Heading** | `--font-heading` | 1.4rem | 副標題、分數顯示、Combo 顯示（非動畫） |
| **Body Large** | `--font-body-large` | 1.15rem | 歌曲卡片標題、按鍵提示、提示訊息 |
| **Body** | `--font-body` | 1rem | 按鈕文字、音訊錯誤、解鎖提示文字等 |
| **Caption** | `--font-caption` | 0.9rem | 難度描述、英文難度名稱、Tooltip、註解等 |
| **Mini Text** | `--font-mini` | 0.8rem | 極小畫面輔助用字、裝飾用途 |

### **遊戲動態元素 - 情境化大小**

| 類型 | 變數名稱 | 桌面大小 | 用途 |
|------|----------|----------|------|
| **Game Combo** | `--font-game-combo` | 3.5rem | Combo 動畫 |
| **Game Countdown** | `--font-game-countdown` | 4.5rem | 倒數動畫 |
| **Game Score** | `--font-game-score` | 1.6rem | 遊戲中分數 |

## 📱 響應式設計系統

### **平板 (768px - 1023px)**
```css
--font-display: 2.4rem;
--font-section: 1.5rem;
--font-heading: 1.2rem;
--font-body-large: 1rem;
--font-game-combo: 3rem;
--font-game-countdown: 4rem;
```

```css
--font-display: 2rem;

--font-heading: 1.1rem;
--font-body-large: 1rem;
--font-caption: 0.85rem;
--font-game-combo: 2.5rem;
--font-game-countdown: 3.5rem;
```

```css
--font-display: 1.8rem;

--font-game-countdown: 3rem;
```

## 🎨 視覺權重重新分配

### **優化前後對比**

| 元素類型 | 優化前 | 優化後 | 理由 |
|----------|--------|--------|------|
| **遊戲標題** | 3.5rem | 2.8rem | 保持權威感，不壓縮其他元素 |
| **區塊標題** | 2rem | 1.75rem | 建立更和諧的視覺階梯 |
| **分數顯示** | 2.2rem | 1.6rem | 重要但不搶奪標題注意力 |
| **Combo 顯示** | 4rem | 3.5rem | 保持刺激感但更平衡 |
| **按鈕文字** | 1.1rem | 1rem | 標準可讀性，避免過大 |
| **輔助文字** | 0.75rem | 0.9rem | 改善可讀性，符合最小標準 |

## ♿ 可訪問性增強

### **高對比度模式**
```css
@media (prefers-contrast: high) {
  :root {
    --font-caption: 1rem;
    --font-mini: 0.9rem;
  }
}
```

### **減少動畫模式**
```css
@media (prefers-reduced-motion: reduce) {
  .combo-animation { font-size: var(--font-heading); }
}
```

## 🔧 維護性提升

### **CSS 變數系統**
- 集中管理所有字體大小
- 一鍵調整整個設計系統
- 確保視覺一致性

### **設計系統類別**
```css
.text-display { font-size: var(--font-display); }
.text-section { font-size: var(--font-section); }
.text-heading { font-size: var(--font-heading); }
.text-body-large { font-size: var(--font-body-large); }
.text-body { font-size: var(--font-body); }
.text-caption { font-size: var(--font-caption); }
.text-mini { font-size: var(--font-mini); }
```

## 🎮 遊戲性與動態識別感

### **動態元素保持刺激感**
- Combo 動畫：3.5rem（保持視覺衝擊）
- 倒數動畫：4.5rem（強調緊迫感）
- 按鍵反饋：即時視覺回饋

### **靜態 UI 注重可讀性**
- 標題層次清晰
- 按鈕文字易讀
- 輔助資訊不搶眼

## 📊 實際應用效果

### **視覺層次清晰**
- 主要標題 → 區塊標題 → 內容文字
- 遊戲元素 → 介面元素 → 輔助資訊
- 動態效果 → 靜態內容

### **響應式適配完善**
- 桌面：完整體驗
- 平板：適度縮放
- 手機：重點突出
- 小螢幕：核心功能

### **可訪問性支援**
- 高對比度模式
- 減少動畫模式
- 最小可讀性標準

## 🎯 設計原則總結

1. **一致性**：統一的字體大小規範
2. **可讀性**：確保所有文字都清晰易讀
3. **層次性**：明確的視覺層次結構
4. **響應性**：適配各種螢幕尺寸
5. **可訪問性**：支援不同用戶需求
6. **遊戲性**：保持遊戲的視覺刺激

這樣的設計系統既保持了遊戲的視覺衝擊力，又建立了更專業、一致的設計語言！
